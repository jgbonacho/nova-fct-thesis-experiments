# NOVA FCT Thesis Experiments

This repository contains the source-code artifacts, network datasets and archived experimental results produced for the calibration of the FADDIS stopping criterion.

## Repository Structure

- [`src/`](./src/) — Source-code artifacts implementing the calibration of the FADDIS stopping criterion.
- [`networks/`](./networks/) — Generated synthetic networks and preprocessed real-world networks used in the experiments.
- [`archive/`](./archive/) — Archive of the experimental results.
